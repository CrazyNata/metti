# AI-стилист Metti: skills и промты

В Metti действует единый контракт стилиста. Запросы из приложения и MCP проходят через один `StylistService`, поэтому правила ниже не расходятся между двумя каналами.

## Skills генератора образов

| Skill | Что контролирует |
| --- | --- |
| `wardrobe_grounding` | Только реальные `itemId` из `availableItems`, без выдуманных вещей. |
| `outfit_architecture` | Полную базу: платье + обувь или верх + низ + обувь; верхняя одежда — дополнительный слой. |
| `visual_styling` | Цвет, силуэт, объём, длину, фактуры, принты и визуальный вес обуви. |
| `context_fit` | Погоду, температуру, сезон, место, повод и формальность. |
| `wear_rotation` | Историю носки, недоиспользованные вещи и избежание постоянных повторов. |
| `variant_diversity` | Реально разные варианты без дубликатов. |
| `selected_anchor` | Сохранение выбранной вещи в каждом варианте. |
| `locked_restyle` | Сохранение locked-вещей и минимальный осмысленный рестайлинг. |
| `capsule_planning` | Покрытие сценариев поездки небольшим числом взаимосочетаемых вещей. |
| `shopping_gap_analysis` | Поиск категорий, которые расширят гардероб, без подмены покупки уже имеющейся вещью. |
| `explainable_advice` | Короткое объяснение и только реальные предупреждения. |
| `quality_gate` | Финальную проверку ID, базы, обуви, якорей, дубликатов и языка ответа. |

## Как это исправляет запрос «куртка и кроссовки»

Куртка и кроссовки становятся якорями, но не считаются полным образом. Стилист дополнительно ищет доступные базовый верх и низ. После ответа backend ещё раз проверяет структуру и отбрасывает вариант только из куртки и обуви, если в гардеробе есть подходящая база.

## Режимы и промты

### Сегодня

«Собери несколько разных полноценных образов на сегодня. Используй только вещи из гардероба. Учти погоду, повод, формальность, стиль и историю носки. Верхнюю одежду добавляй поверх базы».

### Вокруг выбранной вещи

«Создай варианты вокруг `selectedItemId`. Эта вещь обязательна в каждом варианте и не может быть заменена. Подбери остальные категории так, чтобы получился полный образ».

### Рестайлинг

«Улучши текущий образ, сохрани все `lockedItemIds`, измени минимально необходимое и не возвращай дубликат. Проверь, что после изменений сохранилась полная база».

### Капсула / поездка

«Собери компактную капсулу для длительности, погоды и активностей поездки. Максимизируй число сочетаний, повторное использование и практичность, избегай почти одинаковых вещей».

### Рекомендации покупок

«Найди приоритетные пробелы гардероба — категории, которые добавят несколько новых сочетаний. Не выдавай отсутствующую вещь как существующий `itemId`».

## Ролевые промты

Кроме генератора используются три специализированные роли:

- классификатор вещи — evidence-first: заполняет только уверенно видимые атрибуты;
- критик — проверяет готовый образ, но не придумывает и не заменяет вещи;
- learner — осторожно обновляет профиль только по устойчивым паттернам и не переопределяет явные настройки.

Версия общего prompt-контракта сейчас `2.0`. После изменения промтов Edge Functions нужно задеплоить заново; обновление Android-приложения для этого не требуется.
